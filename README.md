# Eco-Scan

An eco-friendly scanning app to help track and manage recycling — built with Flutter (frontend) and Django (backend).

## 🔗 Live Links

- **Frontend (App):** [eco-scan-app.netlify.app](https://eco-scan-app.netlify.app/)
- **Backend API:** [eco-scan-1.onrender.com](https://eco-scan-1.onrender.com/)
- **Admin Panel:** [eco-scan-1.onrender.com/admin](https://eco-scan-1.onrender.com/admin/)

## Tech Stack

- **Frontend:** Flutter
- **Backend:** Django, Django REST Framework
- **Database:** SQLite
- **Hosting:** Netlify (frontend), Render (backend)
